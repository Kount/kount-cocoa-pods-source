# kount-cocoa-pods-source

Kount Cocoapod Client SDK
====================

Kount's Cocoapod SDK helps integrate Kount's fraud fighting solution into
your iOS app.

> **Deprecation notice:** The `Kount` CocoaPods distribution is deprecated as of version 6.0.1 and will receive no further releases. Please migrate to Swift Package Manager using the [Kount Swift iOS SDK](https://github.com/Kount/kount-ios-swift-package).

## Installation

Please follow the [Developer documentation](https://developer.kount.com/hc/en-us/articles/4411898460692) for the complete integration instructions.
